
Программа ищет в интернете списки публичных прокси для Telegram (по
умолчанию — MTProto, по желанию — ещё SOCKS5, HTTP и WEB), проверяет их
(доступность, пинг, настоящий протокол, при желании — стабильность под
нагрузкой) и позволяет одним кликом подключиться к рабочему MTProto-,
SOCKS5- или WEB-прокси в Telegram Desktop.

1. УСТАНОВКА
-------------

Вариант А. Готовый .exe (рекомендуется для обычного пользователя Windows)
  1) Скопируйте в одну папку файлы: TelegramProxyScanner.pyw, build_windows.bat,
     InterUI-Regular.ttf, InterUI-SemiBold.ttf и (не обязательно, но полезно)
     этот README_RU.txt. Два файла шрифта (InterUI-*.ttf) отвечают за красивый
     современный шрифт интерфейса — без них программа тоже запустится и будет
     работать, просто со стандартным шрифтом Windows (Segoe UI).
  2) Запустите build_windows.bat двойным кликом. Python устанавливать заранее
     не обязательно — скрипт сам проверит, есть ли он:
       - если Python не найден — объяснит это и предложит сразу открыть
         страницу загрузки https://www.python.org/downloads/ в браузере
         (при установке обязательно отметьте галочку "Add python.exe to PATH"
         на первом экране) — после установки запустите build_windows.bat ещё раз;
       - если Python уже есть — сам проверит, какие из нужных пакетов
         (pyinstaller, cryptography, pillow) уже установлены, и установит
         только то, чего не хватает (при повторной сборке, когда всё уже
         стоит, никакие пакеты заново не скачиваются — это быстро);
       - в конце соберёт TelegramProxyScanner.exe и скопирует его в эту же
         папку. Пакеты cryptography (быстрая проверка прокси) и Pillow
         (значки на кнопках) оказываются прямо внутри .exe — отдельно
         устанавливать их для готовой программы не нужно.
  3) После надписи "Готово: TelegramProxyScanner.exe" нажмите любую клавишу —
     окно закроется. Запускайте TelegramProxyScanner.exe.
     Если сборка упала с ошибкой — внимательно прочитайте, что написано в
     окне (там указана причина: нет интернета и т.п.).

Вариант Б. Запуск без сборки .exe (для тех, кто уже умеет работать с Python)
  1) Установите Python 3.9+.
  2) Установите зависимости:   pip install cryptography pillow
     (cryptography — быстрая проверка прокси; pillow — значки на кнопках.
     Обе необязательны: без cryptography проверка просто чуть медленнее, без
     pillow кнопки остаются с текстом без значков — программа в любом случае
     запустится и будет работать.)
  3) Убедитесь, что файлы InterUI-Regular.ttf и InterUI-SemiBold.ttf лежат
     рядом с TelegramProxyScanner.pyw (для красивого современного шрифта —
     см. пункт 1 варианта А выше; необязательно, но желательно).
  4) Запустите файл двойным кликом (TelegramProxyScanner.pyw) или командой:
         py TelegramProxyScanner.pyw
     (на Windows можно и без консоли — .pyw запускается без чёрного окна).

Программе не нужны права администратора и установка в систему — её можно
носить на флешке вместе с .exe.


2. ПЕРВЫЙ ЗАПУСК
------------------

При первом запуске рядом с программой автоматически создаются два файла:
  - TelegramProxyScanner_debug.log      — подробный технический журнал работы
                                           (на случай ошибок — приложите его,
                                           если о чём-то спрашиваете).
  - TelegramProxyScanner_settings.json  — сохранённые настройки (появится
                                           после того, как вы нажмёте
                                           "Сохранить настройки").
Оба файла создаются в той же папке, где лежит TelegramProxyScanner.exe/.pyw
(если туда нельзя писать — в вашей домашней папке пользователя).

При каждом следующем запуске программа САМА тихо подгружает последний
сохранённый файл настроек, если он есть — ничего нажимать не нужно.


3. ИСПОЛЬЗОВАНИЕ
------------------

Окно программы состоит из двух вкладок — переключатель находится сверху
справа, рядом с заголовком:
  "Сканирование" — кнопки Лог / Экспорт / Сканировать / Остановить,
                    статистика и таблица найденных прокси. Открывается
                    по умолчанию при запуске.
  "Настройка"     — все параметры поиска и проверки, а также кнопки
                    Сохранить настройки / Загрузить настройки.

Шаг 1 — откройте вкладку "Настройка" и задайте параметры поиска.
Рядом с каждым полем есть значок "?" — наведите на него курсор, чтобы
прочитать короткое объяснение прямо в программе. Основные поля:

  Страна / Провайдер
      Фильтр уже найденных результатов по стране/провайдеру (заполняется
      списком значений после того, как найдутся первые прокси).

  Нужно прокси
      Сколько рабочих прокси нужно найти и показать в списке. Поиск идёт,
      пока не наберётся это количество (или не кончатся кандидаты).

  Макс. ping
      Прокси медленнее этого значения (в мс) не попадают в список.

  Источников (авто)
      Сколько источников списков прокси пытаться найти автоматически —
      используется только вместе с галочкой "Динамический поиск источников"
      (см. ниже).

  Автопроверка ping
      Раз в "Интервал ping" секунд заново проверяет пинг уже найденных
      прокси, чтобы видеть, если один из них отвалился.

  Проверка стабильности + Секунд
      Если включено — перед тем как показать прокси в списке, программа
      проверяет его повторно каждые 0.5 секунды в течение указанного числа
      секунд: для MTProto — через одно удерживаемое соединение, прогоняя
      через него настоящий Telegram-трафик; для SOCKS5/HTTP/WEB — повторяя
      настоящую полную проверку заново на каждом шаге (так строже: ловит и
      обрыв уже установленного соединения, и неспособность прокси стабильно
      принимать новые). Если хоть раз пинг поднимется выше 100 мс (или
      проверка не пройдёт) — прокси отбрасывается и в список НЕ попадает.
      Работает для всех типов прокси, в т.ч. для MTProto с FakeTLS-
      секретами (90% прокси в публичных списках — именно такие).

  Динамический поиск источников
      Если ВЫКЛЮЧЕНО — программа использует свой встроенный список проверенных
      источников (несколько десятков адресов, включая два открытых
      Telegram-канала — urlsources и gidroski, — из которых так же читаются
      последние 50 сообщений, как описано в "Улучшенный поиск" ниже).
      Если ВКЛЮЧЕНО — встроенный список НЕ используется вообще; вместо него
      программа сама ищет свежие списки прокси на GitHub (точные запросы по
      темам mtproto-proxy/telegram-proxy-list плюс текстовые запросы на
      русском, английском и фарси). Поиск ограничен жёстким лимитом по
      времени (порядка 15-20 секунд) — он никогда не растягивается на
      часы, даже если часть сайтов недоступна или отвечает медленно: по
      истечении лимита используется то, что успело найтись.

  Улучшенный поиск
      Доступна только когда включён "Динамический поиск источников".
      Дополнительно к GitHub программа открывает открытую веб-версию
      (t.me/s/...) проверенных Telegram-каналов, которые публикуют прокси
      (плюс живой веб-поиск других похожих каналов/сайтов/форумов), и по-
      настоящему читает последние 50 сообщений каждого канала: достаёт из
      текста сообщений прокси-ссылки, а также переходит по обычным http(s)
      ссылкам на .txt/.json файлы, упомянутым в сообщениях, и проверяет их
      содержимое на прокси тоже. Занимает чуть больше времени (лимит около
      25-30 секунд), но даёт более разнообразный набор источников.
      Важное ограничение: файлы, которые прикреплены к сообщению как
      НАСТОЯЩИЙ файл Telegram (загружены прямо в канал, не просто ссылка),
      технически невозможно скачать без входа в Telegram — такие вложения
      публичная веб-версия канала не отдаёт. Программа это не скрывает: она
      замечает такие вложения и фиксирует их в техническом журнале, но не
      притворяется, что проверила их содержимое.

  Включить другие виды прокси
      Если ВЫКЛЮЧЕНО (по умолчанию) — ищутся и проверяются только MTProto-
      прокси, как раньше.
      Если ВКЛЮЧЕНО — программа дополнительно ищет и проверяет:
        • SOCKS5 — настоящей проверкой: полное рукопожатие SOCKS5 (в т.ч. с
          логином/паролем, если он указан в источнике) и реальный CONNECT
          до серверов Telegram. Подключается в Telegram Desktop в один
          клик точно так же, как MTProto (используется tg://socks).
        • HTTP — настоящей проверкой: HTTP CONNECT до серверов Telegram
          (в т.ч. с Proxy-Authorization, если нужен логин/пароль). У HTTP-
          прокси готового способа подключения в Telegram нет (в Telegram
          Desktop просто не существует такой ссылки) — двойной клик по
          строке покажет адрес сервера и скопирует его в буфер обмена для
          ручной настройки.
        • WEB — настоящий тип прокси в Telegram (HTTPS-сайт на 443 порту с
          секретом, прокидывающий трафик до Telegram через скрытый "мост").
          Проверяется по-настоящему: реальное TLS-рукопожатие с проверкой
          сертификата + HTTP-запрос к серверу — статус "Онлайн (HTTPS
          проверен)". Полную проверку самого "моста" до Telegram Telegram
          сделать нельзя — он не опубликовал её спецификацию, поэтому это
          честно не выдаётся за 100%-ю протокольную проверку, как для
          MTProto/SOCKS5/HTTP. Подключается в Telegram Desktop в один клик,
          как MTProto и SOCKS5 (используется tg://webproxy).
      Тип каждого найденного прокси виден в колонке "Тип" таблицы
      результатов. Проверка стабильности (см. ниже) теперь тоже считается
      для SOCKS5/HTTP/WEB, не только для MTProto.

  Параллельность проверок
      Сколько прокси проверяются одновременно. Меньше значение — медленнее
      сканирование, но меньше нагрузка на ваш интернет-канал (полезно при
      слабом или нестабильном интернете). Больше значение — быстрее
      сканирование на хорошем канале.

  Интервал ping
      Как часто (в секундах) автопроверка обновляет пинг уже показанных
      прокси.

  Скрывать offline
      Не показывать в списке прокси, которые сейчас не отвечают.

  Зафиксировать порядок
      Не переставлять строки местами при обновлении пинга — удобно, если вы
      наводите курсор на список во время автопроверки.

Шаг 2 — перейдите на вкладку "Сканирование" и нажмите "Сканировать".
Статус внизу окна показывает, что именно сейчас происходит (загрузка
источников, проверка прокси и т.д.). В любой момент можно нажать
"Остановить" — уже найденные прокси останутся в списке.

Шаг 3 — подключение. Дважды кликните по строке рабочего прокси:
  - MTProto, SOCKS5 и WEB — прокси будет передан в Telegram Desktop (если
    Telegram установлен и ассоциирован со ссылками tg://, он откроется сам
    с предложением подключиться).
  - HTTP — у Telegram Desktop нет ссылки для подключения таких прокси в
    один клик (такой возможности не существует в принципе — ограничение
    самого Telegram), поэтому программа покажет адрес сервера и скопирует
    его в буфер обмена для ручной настройки.
Одинарный клик просто выделяет строку. Тип прокси показан в колонке "Тип".

Шаг 4 — сохранение настроек. Когда настройки подобраны удобно для вас,
откройте вкладку "Настройка" и нажмите "Сохранить настройки" — при
следующем запуске они подгрузятся автоматически. Кнопка "Загрузить
настройки" позволяет перечитать файл настроек вручную в любой момент
(например, если вы его поправили руками).

Дополнительно (на вкладке "Сканирование"):
  "Экспорт"  — сохранить текущий список найденных прокси в файл.
  "Лог"      — открыть подробный технический журнал
               (TelegramProxyScanner_debug.log) для диагностики.


4. ЧТО ЗНАЧАТ СТАТУСЫ ПРОКСИ В СПИСКЕ
---------------------------------------

  ●  Онлайн - Проверен      — прошёл проверку стабильности: реальная
                               многократная проверка каждые 0.5 сек в
                               течение заданного времени, ping ≤ 100 мс всё
                               время. Работает для всех типов прокси
                               (MTProto, SOCKS5, HTTP, WEB), когда включена
                               галочка "Проверка стабильности".
  ●  Онлайн                 — отвечает и успешно проверен настоящим
                               протоколом: для MTProto — реальным MTProto-
                               рукопожатием, для SOCKS5 — полным SOCKS5-
                               рукопожатием и CONNECT до Telegram, для
                               HTTP — HTTP CONNECT до Telegram.
  ●  Онлайн (HTTPS проверен) — только для WEB: настоящее TLS-рукопожатие
                               (с проверкой сертификата) и HTTP-ответ от
                               сервера прокси получены по-настоящему, но
                               сам "мост" до Telegram (закрытый протокол,
                               см. выше) этим не проверяется — отсюда
                               отдельная, более честная формулировка
                               статуса вместо простого "Онлайн".
  ●  Онлайн (не проверено)  — порт отвечает на TCP-уровне, но ответ именно
                               от Telegram подтвердить не удалось (обычно —
                               нераспознанный MTProto-секрет).
  (не отвечает / недоступен) — прокси сейчас не работает.


5. ЧАСТЫЕ ВОПРОСЫ / РЕШЕНИЕ ПРОБЛЕМ
--------------------------------------

build_windows.bat пишет "Python на этом компьютере не найден"
  — установите Python с https://www.python.org/downloads/ (скрипт сам
    предложит открыть эту страницу) — на первом экране установщика не
    забудьте отметить "Add python.exe to PATH" — и запустите
    build_windows.bat ещё раз.

Сборка .exe упала с ошибкой "не удалось установить зависимости"
  — проверьте интернет-соединение и что Python/pip доступны из командной
    строки (наберите в cmd: py --version).

Сборка .exe упала с ошибкой "сборка PyInstaller не удалась"
  — прочитайте текст ошибки выше в окне; чаще всего это нехватка места на
    диске либо антивирус блокирует PyInstaller — временно отключите его на
    время сборки.

При динамическом поиске источников "Не удалось найти источники"
  — попробуйте ещё раз (список репозиториев на GitHub обновляется, и часть
    запросов зависит от текущей нагрузки на GitHub); увеличьте "Источников
    (авто)"; включите "Улучшенный поиск"; либо просто отключите динамический
    поиск и используйте встроенный список источников.

Прокси находятся, но ни один не проходит проверку
  — проверьте общий доступ в интернет и не блокирует ли файрвол/антивирус
    исходящие соединения программы; подробности всегда есть в
    TelegramProxyScanner_debug.log.
