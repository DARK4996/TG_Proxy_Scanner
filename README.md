# 🚀 Telegram Proxy Scanner

Программа автоматически ищет в интернете публичные прокси для Telegram, проверяет их доступность, пинг, настоящий протокол и, при необходимости, стабильность под нагрузкой.

🔌 Подключайся к рабочим MTProto-, SOCKS5- и WEB-прокси в Telegram Desktop **в один клик**!

По умолчанию программа ищет MTProto-прокси. При желании можно включить поиск и проверку SOCKS5, HTTP и WEB.

## 📦 1. Установка

### 🪟 Вариант A. Сборка готового EXE (рекомендуется для Windows)

Этот вариант подходит для обычных пользователей Windows.

**📁 Шаг 1. Подготовьте файлы**

Скопируйте в одну папку следующие файлы:

- `TelegramProxyScanner.pyw`
- `build_windows.bat`
- `InterUI-Regular.ttf`
- `InterUI-SemiBold.ttf`
- `README.md` (необязательно)

🎨 Два файла шрифта `InterUI-*.ttf` отвечают за современный внешний вид интерфейса. Без них программа также запустится и будет работать, но вместо них будет использоваться стандартный шрифт Windows - Segoe UI.

**🔨 Шаг 2. Запустите сборку**

Дважды щелкните по файлу `build_windows.bat`.

Предварительно устанавливать Python необязательно: скрипт самостоятельно проверит его наличие.

- ❌ **Python не найден:** скрипт предложит открыть [страницу загрузки Python](https://www.python.org/downloads/). При установке обязательно отметьте `Add python.exe to PATH`.
- 📦 **Python уже установлен:** скрипт проверит наличие `pyinstaller`, `cryptography` и `pillow` и установит только недостающие пакеты.
- ✅ **Сборка завершена:** готовый `TelegramProxyScanner.exe` появится в той же папке.

⚡ Библиотеки `cryptography` и `Pillow` включаются непосредственно в EXE. Устанавливать их отдельно для готовой программы не нужно.

**▶️ Шаг 3. Запустите программу**

После сообщения `Готово: TelegramProxyScanner.exe` нажмите любую клавишу, чтобы закрыть окно сборки, и запустите EXE.

⚠️ Если сборка завершилась с ошибкой, внимательно прочитайте сообщение в окне: там обычно указана причина.

### 🐍 Вариант Б. Запуск без сборки EXE

Этот вариант подходит пользователям, которые уже работают с Python.

**1. Установите Python 3.9 или новее.**

**2. Установите зависимости:**

```bash
pip install cryptography pillow
```

- ⚡ `cryptography` - ускоряет проверку прокси.
- 🎨 `pillow` - добавляет значки на кнопки.

Обе библиотеки необязательны: программа будет работать и без них.

**3. Подготовьте шрифты.**

Убедитесь, что `InterUI-Regular.ttf` и `InterUI-SemiBold.ttf` находятся рядом с `TelegramProxyScanner.pyw`.

**4. Запустите программу:**

```bash
py TelegramProxyScanner.pyw
```

💡 В Windows файлы `.pyw` запускаются без появления черного окна консоли.

> 🔋 Программе не нужны права администратора или установка в систему. Ее можно хранить на флешке вместе с готовым EXE.

## 🆕 2. Первый запуск

При первом запуске рядом с программой автоматически создаются следующие файлы:

| 📄 Файл | 📝 Назначение |
|---|---|
| `TelegramProxyScanner_debug.log` | 🔍 Подробный технический журнал для диагностики ошибок |
| `TelegramProxyScanner_settings.json` | ⚙️ Сохраненные настройки программы |

📂 Оба файла располагаются рядом с `TelegramProxyScanner.exe` или `TelegramProxyScanner.pyw`. Если запись в эту папку невозможна, файлы создаются в домашней папке пользователя.

💾 После сохранения настроек программа автоматически загружает их при каждом следующем запуске.

🆘 Если понадобится помощь, приложите файл `TelegramProxyScanner_debug.log` - он поможет определить причину ошибки.

## ⚙️ 3. Использование

Окно программы состоит из двух вкладок:

- 🔎 **Сканирование** - поиск прокси, проверка результатов, статистика, журнал и экспорт.
- 🛠️ **Настройка** - параметры поиска и проверки, сохранение и загрузка настроек.

### 🔧 Шаг 1. Настройте поиск

Откройте вкладку **«Настройка»** и задайте необходимые параметры.

💡 Рядом с каждым полем есть значок `?`. Наведите на него курсор, чтобы прочитать краткое объяснение.

#### 📋 Основные параметры

| Параметр | Описание |
|---|---|
| 🌍 **Страна / Провайдер** | Фильтрация найденных прокси по стране или провайдеру. |
| 🎯 **Нужно прокси** | Сколько рабочих прокси требуется найти. |
| ⚡ **Макс. ping** | Максимальный допустимый пинг в миллисекундах. |
| 🔍 **Источников (авто)** | Количество источников, которые программа попытается найти автоматически. |
| 🔄 **Автопроверка ping** | Повторная проверка пинга уже найденных прокси. |
| 🛡️ **Проверка стабильности + Секунд** | Многократная проверка надежности соединения. |
| 🌐 **Динамический поиск источников** | Автоматический поиск новых списков прокси на GitHub. |
| 🧭 **Улучшенный поиск** | Поиск дополнительных источников в открытых Telegram-каналах, на сайтах и форумах. |
| 🔌 **Включить другие виды прокси** | Добавляет поиск SOCKS5, HTTP и WEB. |
| ⚙️ **Параллельность проверок** | Количество прокси, проверяемых одновременно. |
| ⏱️ **Интервал ping** | Период обновления пинга найденных прокси. |
| 👻 **Скрывать offline** | Скрывает прокси, которые сейчас не отвечают. |
| 📌 **Зафиксировать порядок** | Не позволяет строкам перемещаться при обновлении пинга. |

#### 🛡️ Проверка стабильности

Если функция включена, программа повторно проверяет прокси каждые 0,5 секунды в течение заданного времени.

- 🔗 **MTProto:** используется одно удерживаемое соединение с настоящим Telegram-трафиком.
- 🔄 **SOCKS5 и HTTP:** на каждом шаге заново выполняется полная проверка протокола.
- 🔒 **WEB:** повторно проверяется HTTPS-сервер с проверкой TLS-сертификата и HTTP-ответа.

❌ Если хотя бы одна проверка не проходит или пинг превышает 100 мс, прокси отбрасывается и не попадает в список.

#### 🌐 Динамический поиск источников

Если функция выключена, используется встроенный список проверенных источников, включая открытые Telegram-каналы `urlsources` и `gidroski`.

Если функция включена, программа самостоятельно ищет свежие списки прокси на GitHub, используя тематические запросы и поисковые фразы на русском, английском и фарси.

⏱️ Поиск ограничен примерно 15-20 секундами. По истечении лимита используются источники, которые удалось найти.

#### 🧭 Улучшенный поиск

Помимо GitHub, программа обращается к открытым веб-версиям Telegram-каналов (`t.me/s/...`), а также ищет похожие каналы, сайты и форумы.

Программа:

- 🔗 Извлекает прокси-ссылки из сообщений.
- 📥 Переходит по HTTP(S)-ссылкам на файлы `.txt` и `.json`.
- 🔎 Проверяет содержимое найденных файлов на наличие прокси.

⏱️ Поиск занимает примерно 25-30 секунд, но позволяет получить более разнообразный набор источников.

> ⚠️ **Ограничение:** файлы, прикрепленные непосредственно к сообщениям Telegram, невозможно скачать через публичную веб-версию канала без входа в Telegram. Программа фиксирует такие вложения в журнале, но не утверждает, что проверила их содержимое.

#### 🔌 Поддерживаемые типы прокси

**🔷 MTProto**
- Основной тип прокси, включенный по умолчанию.
- Проверка настоящим протоколом.
- Подключение в один клик.

**🧦 SOCKS5**
- Полное рукопожатие SOCKS5.
- Поддержка логина и пароля.
- Реальная проверка CONNECT до серверов Telegram.
- Подключение через `tg://socks`.

**🌍 HTTP**
- Проверка HTTP CONNECT до серверов Telegram.
- Поддержка `Proxy-Authorization`.
- Адрес сервера можно скопировать для ручной настройки.

**🔒 WEB**
- Проверка HTTPS-сервера с TLS-рукопожатием и проверкой сертификата.
- Подключение через `tg://webproxy`.
- Полная проверка скрытого моста до Telegram невозможна из-за отсутствия опубликованной спецификации.

💡 Тип каждого прокси отображается в колонке **«Тип»**. Проверка стабильности работает для всех четырех типов.

### ▶️ Шаг 2. Запустите сканирование

Перейдите на вкладку **«Сканирование»** и нажмите **«Сканировать»**.

В нижней части окна отображается текущий этап работы:

- 📥 Загрузка источников.
- 🔎 Поиск прокси.
- ⚡ Проверка соединений.
- 📊 Обновление результатов.

⏹️ В любой момент можно нажать **«Остановить»**. Уже найденные прокси останутся в списке.

### 🔗 Шаг 3. Подключитесь к прокси

Дважды щелкните по строке рабочего прокси.

| Тип | Действие |
|---|---|
| 🔷 MTProto | Открывает Telegram Desktop со ссылкой подключения |
| 🧦 SOCKS5 | Использует ссылку `tg://socks` |
| 🔒 WEB | Использует ссылку `tg://webproxy` |
| 🌍 HTTP | Показывает адрес сервера и копирует его в буфер обмена |

Для MTProto, SOCKS5 и WEB требуется установленный Telegram Desktop с поддержкой ссылок `tg://`.

⚠️ HTTP-прокси нельзя подключить таким способом: Telegram Desktop не предоставляет соответствующей ссылки.

👆 Одинарный щелчок только выделяет строку. Тип прокси отображается в колонке «Тип».

### 💾 Шаг 4. Сохраните настройки

1. Откройте вкладку **«Настройка»**.
2. Нажмите **«Сохранить настройки»**.

При следующем запуске настройки загрузятся автоматически.

Кнопка **«Загрузить настройки»** позволяет перечитать файл `TelegramProxyScanner_settings.json` вручную.

### 🧰 Дополнительные возможности

- 📤 **Экспорт** - сохранение текущего списка найденных прокси в файл.
- 📋 **Лог** - открытие технического журнала `TelegramProxyScanner_debug.log`.

## 📊 4. Что значат статусы прокси в списке

| Статус | Значение |
|---|---|
| 🟢 **Онлайн - Проверен** | Пройдена проверка стабильности с повторными проверками каждые 0,5 секунды и пингом не выше 100 мс. |
| 🟢 **Онлайн** | Прокси отвечает и успешно прошел проверку настоящим протоколом. |
| 🔒 **Онлайн (HTTPS проверен)** | Для WEB успешно проверены TLS-соединение, сертификат и HTTP-ответ. Сам мост до Telegram не проверен. |
| 🟡 **Онлайн (не проверено)** | Порт отвечает, но подтвердить ответ именно от Telegram не удалось. Возможная причина - нераспознанный MTProto-секрет. |
| 🔴 **Не отвечает / недоступен** | Прокси в данный момент не работает или не отвечает на проверку. |

## 🛠️ 5. Частые вопросы и решение проблем

### ❌ `build_windows.bat` сообщает: «Python на этом компьютере не найден»

Установите Python с [официального сайта](https://www.python.org/downloads/).

Во время установки обязательно отметьте `Add python.exe to PATH`, завершите установку и запустите `build_windows.bat` повторно.

### 📦 Сборка EXE завершилась ошибкой установки зависимостей

Проверьте подключение к интернету и доступность Python и `pip`.

Выполните в командной строке:

```bash
py --version
```

### 🔨 Сборка PyInstaller завершилась ошибкой

Проверьте текст ошибки в окне сборки.

Возможные причины:

- 💽 Недостаточно свободного места на диске.
- 🛡️ Антивирус блокирует работу PyInstaller.

Если проблема связана с антивирусом, проверьте журнал блокировок и при необходимости настройте исключение для доверенных файлов проекта.

### 🔍 Не удалось найти источники при динамическом поиске

Попробуйте:

1. 🔄 Запустить поиск повторно.
2. 📈 Увеличить параметр **«Источников (авто)»**.
3. 🧭 Включить **«Улучшенный поиск»**.
4. ⚙️ Отключить динамический поиск и использовать встроенный список.

Количество доступных репозиториев и результаты поиска на GitHub могут меняться.

### 🔴 Прокси находятся, но ни один не проходит проверку

Проверьте:

- 🌐 Работает ли интернет-соединение.
- 🛡️ Не блокирует ли файрвол или антивирус исходящие соединения программы.
- 📋 Нет ли дополнительной информации об ошибках в `TelegramProxyScanner_debug.log`.

Если проблема сохраняется, изучите технический журнал: он содержит подробности поиска и проверки соединений.
